# Contributing to CUA Agent Kit

Contributions are welcome. Please follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Contributor License Agreement

Before contributing to this CVS Health sponsored project, you will need to sign
the associated [Contributor License Agreement (CLA)](https://forms.cloud.microsoft/r/iFxA6AApy1).

## Submitting a Pull Request

Fork the repository and submit a pull request from your fork. Keep your fork
up to date with `main`, keep changes focused, and explain how you verified them.

## Code Style and Checks

We use **Ruff** for linting and formatting and **ty** for type checking. Run the
[development checks](README.md#development-checks) before submitting a pull
request. See the [README](README.md#setup) for development setup.

## AI-Assisted Contributions

You are responsible for any code you submit, regardless of whether it was
written manually or generated by AI. You must understand and be able to explain
your changes and the existing code they affect.

Do not use AI to speak for you in issues, pull requests, or discussions, aside
from translation or grammar editing. Human to human communication is important
to keep this community healthy.
